# RoboHash

This is a Raycast extension for [RoboHash](https://robohash.org/) - _Robots lovingly delivered by Robohash.org_.

This extension allows you to generate unique images from any text with advanced settings.

## Arguments

- Text: The actual text to use
- Background Set - Choose from multiple background
- Set - Choose from the following:
    
    1. Zikri Kader (set1)
    2. Hrvoje Novakovic (set2)
    3. Julian Peter Arias (set3).
    4. Cats (set4) were created by David Revoy
    5. [avataaars](https://avataaars.com/) (set5) were created by [Pablo Stanley](https://twitter.com/pablostanley)
    6. Gorillas (set6) created [OceanSlim](https://github.com/0ceanSlim)
